Architecture

One clean layer above Skillshare. Zero forks.

Instead of reinventing skill packaging or security audits, Livery wraps stock upstream skillshare as its per-host engine and manages everything that spans machines, roles, prompts, and accounts in ~/.local/share/livery.

Deep Dive

Built for real multi-host agent workflows.

Explore how Livery connects declarative Git configuration with live day-to-day experimentation across machines.

Edit in Git, or edit live on a remote Linux box — never lose either.

Opening a remote host's Skillshare tab inside liv ui spins up an ephemeral SSH loopback tunnel with a stdin-EOF watchdog (zero orphan processes on disconnect). Install or tweak a skill directly on the remote machine and Livery's SSE watcher immediately lights up Sync · ↑1 so you can pull it back into your shared Catalog. 

$ liv sync --target ops@linux-node   # Push & tag livery-base
$ liv drift                          # Inspect remote host edits
$ liv pull --target ops@linux-node   # Adopt back into Catalog

Compose profiles once. Override per host in one click.

Define reusable bundles like base, workstation, and server-ops across skills, MCP servers, hooks, plugins, prompts, and launchers. Inherited items appear in blue with profile guardrails; per-host additions and exclusions are toggled directly in the Matrix. 

# profiles/workstation.toml
id = "workstation"
extends = ["base"]
mcp = ["github"]
hooks = ["notify-turn-complete"]
launchers = ["claude-gateway", "claude-personal", "codex-zai"]

[skills]
include = ["playwright-qa", "release-audit"]

Keep CLAUDE.md and AGENTS.md sharp, ranked, and within budget.

Break monolithic global prompt files into modular +++ Markdown fragments with live word-count tracking. Rank them globally (#1 → #N) in Catalog → Prompts, filter per provider, and review every compiled change in Livery's built-in Git diff modal. 

+++
id = "engineering/verify-first"
providers = ["claude", "codex"]
why = "Run unit tests and linters before declaring work done"
+++
## Verification
- Run the project's relevant test and lint targets after edits.

Multiple accounts, shared skills, Keychain secrets, and Cmd+Shift+N in Herdr.

liv claude gateway and liv claude personal run in lightweight Shadow Homes that symlink your Skillshare skills and prompts while keeping OAuth tokens and store: Keychain secrets strictly separate. Install the embedded Herdr mod to launch any profile on any local or remote space via Cmd+Shift+N. 

$ liv secret set gateway-api-key
$ liv secrets sync --target ops@linux-node
$ liv herdr install-mod
$ liv claude gateway --permission-mode plan

Onboard new hosts and adopt existing native setups in seconds.

liv env discover finds hosts across Herdr, Tailscale, and ~/.ssh/config. When you open a host in liv ui, the Native & External scanner inspects ~/.claude and ~/.codex over SSH so you can pull pre-existing skills, MCP servers, or hooks into your Catalog or mark them external. 

$ liv env discover
$ liv env add ops@linux-node --profiles base,server-ops
$ liv env bootstrap ops@linux-node --skillshare
$ liv doctor

Get Started

Up and running in four commands.

Livery keeps your configuration in ~/.local/share/livery and never touches unmanaged files without explicit adoption.

1

Install & Onboard

Install static liv + stock skillshare, then run interactive health & setup checks.

curl -fsSL https://raw.githubusercontent.com/bowd/livery/main/install.sh | sh
brew install skillshare
liv onboard --apply
2

Discover & Bootstrap SSH Hosts

Probe remote Mac, Linux, or NixOS boxes and stream static liv + skillshare over SSH.

liv env discover
liv env add ops@linux-node --profiles base,server-ops
liv env bootstrap ops@linux-node --skillshare
3

Compose in Meta-UI & Sync

Curate skills, MCP servers, hooks, Matrix rules, and ranked prompt fragments visually.

liv ui
liv plan
liv sync
4

Create Profiles & Launch

Use built-in blueprints for gateways or second OAuth accounts and launch from CLI or Herdr.

liv profile new
liv secret set gateway-api-key
liv claude gateway --permission-mode plan
