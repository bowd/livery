Main use cases

When plain single-machine dotfiles or single-account CLIs stop scaling.
01 · Multi-Machine Laptop + SSH Servers

Keep MacBooks and remote Linux boxes in sync

✕SSH servers miss your local skills & MCP; edits made remotely stay stranded.
✓Push over SSH, open the remote Skillshare UI via tunnel, and pull edits back.
$liv env add ops@linux-node && liv sync
02 · Multi-Account Work + Personal

Run work gateways & personal plans side-by-side

✕Switching between company LiteLLM, personal Max, and custom providers overwrites auth.
✓Shadow Homes isolate logins & Keychain keys while sharing all your skills & hooks.
$liv claude gateway --permission-mode plan
03 · Machine Roles Workstation vs. Server

Deploy different toolsets per machine role

✕Syncing one flat config puts browser tools on headless servers or prod DB tools everywhere.
✓Compose base, workstation, and server-ops profiles in one Matrix.
$liv ui # Toggle per-host rules in Matrix
04 · Global Prompts CLAUDE.md & AGENTS.md

Maintain global instructions in one place

✕Hand-editing ~/.claude/CLAUDE.md and ~/.codex/AGENTS.md drifts and bloats context.
✓Rank small Markdown prompt fragments once; Livery compiles clean files per tool.
$liv plan # Preview compiled prompt diffs
Bonus — Herdr, T3 Code & OpenClaw integration: press Cmd+Shift+N in Herdr to pick Space → Profile → Launch on any local or remote machine.

See it in action

Every feature works from both the CLI and the local liv ui dashboard.

Push to SSH hosts, or pull remote edits back

  • Safe outward push: compiles each host's skills, MCP, hooks & prompts and tags a baseline snapshot.
  • Instant drift detection: remote edits show up live as Sync · ↑1.
  • Your choice on pull: promote to shared Catalog, fork, or keep as a host-only override.
liv plan --target ops@linux-node
liv sync --target ops@linux-node
liv drift
liv pull --target ops@linux-node

Named agent profiles & Herdr Cmd+Shift+N

  • Direct launch: liv claude gateway [args...] passes all flags straight to the CLI.
  • Shadow Homes: symlinks shared skills & memory pools; isolates OAuth & Keychain keys.
  • Cross-host secrets: sync store: keys over SSH and verify parity via HMAC-SHA256.
liv profile new
liv secret set gateway-api-key
liv secrets sync --target ops@linux-node
liv claude gateway --permission-mode plan

Assign capabilities across hosts in one grid

  • Profile inheritance: workstation and server-ops extend base.
  • Guardrails: blue checkmarks show profile-inherited items; green/dark show host overrides.
  • Unified scope: covers skills, MCP servers, hooks, plugins, prompts, and launchers.
# profiles/workstation.toml
id = "workstation"
extends = ["base"]
mcp = ["github"]
hooks = ["notify-turn-complete"]
launchers = ["claude-gateway", "claude-personal"]

Composable fragments → CLAUDE.md & AGENTS.md

  • Rank once: set global order (#1..#N) across all profiles and machines.
  • Stay within budget: live word counts prevent prompt bloat.
  • Built-in Git review: inspect unified diffs, revert, or commit from the topbar.
+++
id = "engineering/verify-first"
providers = ["claude", "codex"]
+++
## Verification

Open any remote machine's Skillshare UI locally

  • Zero-prereq discovery: finds hosts from Tailscale, Herdr & ~/.ssh/config.
  • Live SSH tunnel: proxies remote skillshare ui into your browser Read/Write.
  • Adopt existing setups: scans ~/.claude & ~/.codex to import unmanaged items.
liv env discover
liv env add ops@linux-node --profiles base,server-ops
liv env bootstrap ops@linux-node --skillshare
liv ui

How it works under the hood

Plain TOML & Markdown in ~/.local/share/livery — wraps stock skillshare with zero forks.
Control Plane · ~/.local/share/livery Git-backed
inventory.toml Your local & SSH machines + assigned profiles
catalog/skillshare/ Central library of skills, MCP servers, hooks & plugins
profiles/*.toml Reusable role bundles (base, workstation, server-ops)
prompts/fragments/ Ranked Markdown blocks compiled per harness
launchers/*.toml Named account profiles + symbolic Keychain store: refs
liv sync ──▶
SSH Tunnel
◀── liv pull
Each Machine · Mac, Linux or NixOS Native files
skillshare sync Installs selected skills, MCP & hooks into each coding tool
~/.claude & ~/.codex Gets compiled CLAUDE.md & AGENTS.md instructions
Shadow Homes Lets multiple accounts run at once with shared skills
Keychain / 0600 Holds actual API keys locally (never committed to Git)
livery-base tag Tracks local edits on the machine for clean liv pull

Common commands

Install liv + skillshare, then run liv onboard --apply.
Accounts, Launching & Secrets
liv claude gateway [args...] Launch named profile (passes all flags verbatim)
liv list List configured profiles & secret status
liv profile new Create a gateway, OAuth, or custom-provider profile
liv group set claude gateway work Share session history across selected profiles
liv secret set <name> Store API key in macOS Keychain / 0600 file
liv secrets sync Copy required secrets to SSH hosts
Machines, Sync & Web UI
liv onboard --apply Check setup & apply recommended fixes
liv ui Open local dashboard & SSH-tunneled Skillshare
liv env discover Find Tailscale, Herdr & ~/.ssh/config machines
liv env bootstrap <id> --skillshare Install liv & skillshare on a remote host
liv plan / liv sync / liv pull Preview changes, push to hosts, or pull edits back
liv doctor Verify sync state, Herdr mod & secret parity
