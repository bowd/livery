Core workflows

Click a workflow to inspect its config and live UI.

Push from Git, or pull remote edits back

  • Baseline tags: every liv sync snapshots a livery-base Git tag on the host.
  • Live SSE detection: remote edits surface as Sync · ↑1 immediately.
  • Granular pull: promote to Catalog, fork per host, or save as a host override.
liv plan --target ops@linux-node
liv sync --target ops@linux-node
liv drift
liv pull --target ops@linux-node

Stock Skillshare UI, tunneled over SSH

  • Sandboxed Catalog: curate your full library without touching live ~/.claude.
  • SSH loopback tunnel: opens remote Linux skillshare ui Read/Write inside Livery.
  • Zero orphans: stdin-EOF watchdog stops the remote UI process on close.
liv env discover
liv env add ops@linux-node --profiles base,server-ops
liv env bootstrap ops@linux-node --skillshare
liv ui

Composable profiles + per-host Matrix

  • Inheritance: workstation and server-ops extend base.
  • Profile guardrails: blue checkmarks prevent accidental edits to shared profiles.
  • All categories: skills, MCP, hooks, plugins, prompts, and launchers in one grid.
# profiles/workstation.toml
id = "workstation"
extends = ["base"]
mcp = ["github"]
hooks = ["notify-turn-complete"]
launchers = ["claude-gateway", "claude-personal"]

Ranked fragments → lean CLAUDE.md & AGENTS.md

  • Global rank: order fragments #1..#N once across all profiles.
  • Context budget: live word counts keep always-loaded files under ~60 lines.
  • Built-in Git modal: diff, revert, or commit control-plane edits from the topbar.
+++
id = "engineering/verify-first"
providers = ["claude", "codex"]
+++
## Verification
- Run unit tests and linters after edits.

Multi-account Shadow Homes & Herdr wizard

  • Direct execve: liv claude gateway [args...] passes all flags verbatim.
  • Zero-leak secrets: macOS Keychain + salted HMAC-SHA256 SSH parity checks.
  • Herdr mod: Cmd+Shift+N opens Space → Profile → Launch on any machine.
liv profile new
liv secret set gateway-api-key
liv secrets sync --target ops@linux-node
liv herdr install-mod

CLI at a glance

Single static binary (liv), zero runtime dependencies.
Launch Profiles & Secrets
liv claude gateway [args...] Launch profile (passes trailing flags verbatim)
liv list List profiles, auth modes, and secret status
liv profile new Interactive wizard for gateways & OAuth accounts
liv group set claude gateway work Pool sessions & memory across Shadow Homes
liv secret set <name> Save secret to macOS Keychain / 0600 store
liv secrets sync Stream required store: secrets over SSH
Fleet Control & Companion Apps
liv onboard --apply Guided setup checklist & one-step fixes
liv ui Open Meta-UI & embedded Skillshare slots
liv env discover Find Tailscale, Herdr & ~/.ssh/config hosts
liv env bootstrap <id> --skillshare Cross-compile liv & install skillshare via SSH
liv plan / liv sync / liv pull Preview, push outward, or pull host edits back
liv herdr install-mod Install Cmd+Shift+N launcher mod into Herdr
